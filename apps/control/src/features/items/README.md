# apps/control/src/features/items

The page's one item editor ("Editar item"): preparing a new item for a rundown or a quick-fire panel,
and changing a stored one, for any graphic. Start at `ItemEditorPanel.tsx`; the rundown column draws it.

- `ItemEditorTargetProvider.tsx` — what the editor is open for, for the whole page: the rundown, the
  quick-fire strip, and "Salvar como item" of "Edição rápida" (a new item with a prefill).
- `ItemEditorPanel.tsx` + `ItemEditorHeader.tsx` + `ItemEditorButtons.tsx` — the editor's two forms and
  its buttons; `useItemEditorSaves.ts` — what a press sends: "Salvar item" (`createItem`, or
  `updateItemFields` with only what changed), "Atualizar no ar"; `ItemHomeSelect.tsx` is "Onde".
- `ItemEditorFormFields.tsx`, `FormFieldRow.tsx`, `itemEditorForm.ts`, `itemEditorFormResolver.ts`,
  `useFirstGraphicForNewItemOnceKnown.ts` — the fields every item has; `ItemGraphicFieldsForm.tsx`,
  `graphicFieldsOfItemEditor.ts` — the graphic's own, generated by features/schemaForm.
- `itemCommandsFromEditor.ts` — the three commands; `itemsTheServerMayStore.ts`,
  `storedItemAfterAcceptedSave.ts` — what the next save compares with.
- `ItemColorChip.tsx`, `itemColorChip.ts`, `itemColorButton.ts` — an item's colour, dot or button.

# apps/control/src/features/items

The page's one item editor ("Editar item"): preparing a new item for a rundown or a quick-fire panel,
and changing a stored one, for any graphic. Start at `ItemEditorPanel.tsx`; the rundown column draws it.

- `ItemEditorTargetProvider.tsx` — what the editor is open for, for the whole page: the rundown, the
  quick-fire strip, "Novo gráfico…" of "Edição rápida", and "Salvar como item" on a Camadas row (a
  new item with a prefill).
- `ItemEditorPanel.tsx` + `ItemEditorHeader.tsx` + `ItemEditorButtons.tsx` — the editor's two forms and
  its buttons; `useItemEditorSaves.ts` — what a press sends: "Salvar item" (`createItem`, or
  `updateItemFields` with only what changed), "Salvar e disparar" / "Salvar e prévia" (then
  `takeItem` / `previewItem`), "Atualizar no ar"; `ItemHomeSelect.tsx` is "Onde".
- `ItemEditorFormFields.tsx`, `FormFieldRow.tsx`, `itemEditorForm.ts`, `itemEditorFormResolver.ts` —
  the fields every item has (a new item opens with no graphic chosen: "Escolha um gráfico…", and the
  save buttons are off until one is); `ItemGraphicFieldsForm.tsx`, `graphicFieldsOfItemEditor.ts` —
  the graphic's own, generated by features/schemaForm, drawn only once a graphic is chosen.
- `itemCommandsFromEditor.ts` — the three commands; `itemsTheServerMayStore.ts`,
  `storedItemAfterAcceptedSave.ts` — what the next save compares with.
- `ItemColorChip.tsx`, `itemColorChip.ts`, `itemColorButton.ts` — an item's colour, dot or button.

What redraws when (BAJAOVRLAY-45, `ItemEditorPanelRenders.test.tsx` counts it): a poll of a source redraws
no field row, only the "Valor agora" line whose text it changed; a pick or a keystroke redraws its own
field only. So nothing in or above the editor subscribes to what changes at every poll (the rundown's and the
console's keyboard shortcuts read the instances at the press): the panel selects
"is this item on air" (a yes or no), the graphic's form reads the sources once at opening, and
`useBindingOptionsOfItemEditor.ts` hands the sources' ids and names (compared text by text) and the store's
subscription for "Valor agora". The guard in a real browser is `e2e/itemEditorStaysFastDuringARace.e2e.ts`.
